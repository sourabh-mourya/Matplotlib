## Importing Matplotlib

Matplotlib use karne ke liye sabse pehle `pyplot` module import kiya jaata hai:

```python
import matplotlib.pyplot as plt
```

`pyplot` module hume multiple built-in functions provide karta hai, jaise:

* `plt.plot()` – Line graph ke liye
* `plt.bar()` – Bar chart ke liye
* `plt.pie()` – Pie chart ke liye
* `plt.hist()` – Histogram ke liye
* `plt.scatter()` – Scatter plot ke liye
* `plt.xlabel()` – X-axis label set karne ke liye
* `plt.ylabel()` – Y-axis label set karne ke liye
* `plt.title()` – Graph ka title dene ke liye
* `plt.show()` – Graph display karne ke liye

## Important Terms in Matplotlib

Matplotlib ka use karte waqt kuch basic terms ka clear hona bahut zaroori hota hai. Ye terms samajhne se graphs banana aur unhe customize karna easy ho jaata hai.

### 1. Data Point

* Data point ek **single value** hoti hai jo X-axis aur Y-axis ke combination se banti hai.
* Example: Agar ek student ne **Day 1 par 80 marks** score kiye hain, to ye data point `(1, 80)` hoga.

  * `1` → X-axis par (Day)
  * `80` → Y-axis par (Marks)

### 2. X-axis

* X-axis **horizontal axis** hoti hai.
* Is par generally **input values** ya independent variables hote hain.
* Example: Days, Time, Categories, Student IDs

### 3. Y-axis

* Y-axis **vertical axis** hoti hai.
* Is par mostly **output values** ya dependent variables hote hain.
* Example: Sales, Temperature, Marks, Profit

### 4. Figure

* Figure poora **canvas ya window** hota hai jisme graph display hota hai.
* Matlab complete image jisme aapka visualization dikh raha hota hai.

### 5. Axes

* Axes wo **actual area** hota hai jahan graph draw hota hai.
* Ek figure ke andar **ek se zyada axes** ho sakte hain (subplots ke case mein).

### 6. Plot

* Plot actual **line, bar, ya shape** hota hai jo data ko represent karta hai.
* Example: Line plot, bar plot, scatter plot

### 7. Marker

* Marker ek **symbol** hota hai jo har data point ko clearly show karta hai.
* Common markers:

  * `o` → Circle
  * `s` → Square
  * `D` → Diamond

### 8. Line Style

* Line style batata hai ki line graph ke andar **kaise draw hogi**.
* Common styles:

  * `-`  → Solid line
  * `--` → Dashed line
  * `:`  → Dotted line

### 9. Color

* Color se hum define karte hain ki line ya bar **kis color** mein draw hogi.
* Example: `red`, `blue`, `green`, `black`

### 10. Legend

* Legend ek **chhota box** hota hai jo batata hai:

  * kaunsi line
  * kaunsa color
  * kis data ko represent kar raha hai

### 11. Label

* Label ka use X-axis aur Y-axis ko **explain** karne ke liye hota hai.
* Example:

  * X-axis → Days
  * Y-axis → Sales

### 12. Title

* Title graph ko ek **heading** deta hai.
* Ye batata hai ki graph kis data ke baare mein hai.

### 13. Grid

* Grid chart mein **reference lines** add karta hai.
* Ye specially **line chart aur bar chart** mein useful hota hai for better readability.

### 14. Function

* Function ek block hota hai jo **specific task perform** karta hai.
* Example: `plt.plot()`, `plt.show()`

### 15. Method

* Method ek function hota hai jo **object ke saath associated** hota hai.
* Example: `ax.plot()`

### 16. Parameters

* Parameters wo values hoti hain jo function ya method ko pass ki jaati hain.
* Example: `plt.plot(x, y)`

### 17. Keyword Arguments

* Keyword arguments ka use parameters ko **name ke saath** pass karne ke liye hota hai.
* Example: `color='red', linestyle='--', marker='o'`

### 18. Object-Oriented API

* Matplotlib ka **Object-Oriented API** approach mein hum `Figure` aur `Axes` objects ke saath kaam karte hain.
* Ye approach large aur complex visualizations ke liye better hota hai.

### 19. DPI (Dots Per Inch)

* DPI image ki **resolution** define karta hai.
* Jab hum graph ko save karte hain, DPI batata hai image kitni clear hogi.
* Higher DPI → Better quality image

### 20. Backend

* Backend batata hai ki Matplotlib **graph ko kaise render** karega.
* Examples:

  * Screen par display ke liye → Interactive backend
  * File (PNG, PDF) save karne ke liye → Non-interactive backend

## Pyplot vs Object-Oriented API in Matplotlib

Matplotlib mein graphs banane ke do major approaches hote hain:

1. Pyplot API
2. Object-Oriented (OO) API

Dono ka use case alag-alag hota hai. Neeche inhe simple language aur examples ke saath explain kiya gaya hai.

---

## 1. Pyplot API

Pyplot API beginners ke liye **easy aur quick** hota hai. Ye internally **global state** ki tarah kaam karta hai, matlab aap directly commands dete ho aur Matplotlib current graph par apply kar deta hai.

### Kab use karein?

* Jab sirf **single plot** banana ho
* Jab data chhota ho
* Jab quick visualization chahiye

### Example (Pyplot API)

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

plt.plot(x, y, marker='o', color='blue')
plt.xlabel('X Values')
plt.ylabel('Y Values')
plt.title('Pyplot Example')
plt.grid(True)
plt.show()
```

Is example mein:

* `plt.plot()` directly current graph par line draw karta hai
* Hume ye specify nahi karna padta ki kaunsa axes use ho raha hai

---

## 2. Object-Oriented (OO) API

Object-Oriented API zyada **powerful aur flexible** hota hai. Is approach mein hum pehle `Figure` aur `Axes` objects create karte hain aur phir unhi objects par plotting karte hain.

Isme hum clearly decide karte hain:

* kaunsa plot
* kaunsa axes
* kaunsa figure

par kaam ho raha hai.

### Kab use karein?

* Jab **large ya complex dataset** ho
* Jab ek window ke andar **multiple graphs (subplots)** banana ho
* Jab professional / production-level visualization chahiye

### Example (Object-Oriented API)

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y1 = [10, 20, 25, 30]
y2 = [5, 15, 20, 25]

fig, ax = plt.subplots()

ax.plot(x, y1, marker='o', label='Dataset 1')
ax.plot(x, y2, marker='s', label='Dataset 2')

ax.set_xlabel('X Values')
ax.set_ylabel('Y Values')
ax.set_title('Object-Oriented API Example')
ax.legend()
ax.grid(True)

plt.show()
```

Is example mein:

* `fig` → complete figure (window)
* `ax` → actual plotting area
* `ax.plot()` → specific axes par plot draw karta hai

---

## Multiple Graphs using Object-Oriented API

Object-Oriented API ka biggest advantage tab dikhta hai jab ek hi window mein multiple graphs chahiye hote hain.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 30, 40]

fig, axs = plt.subplots(1, 2)

axs[0].plot(x, y)
axs[0].set_title('Graph 1')

axs[1].bar(x, y)
axs[1].set_title('Graph 2')

plt.show()
```

Yahan:

* Ek figure ke andar **do axes (subplots)** hain
* Har axes par alag-alag graph draw ho raha hai

---

## Pyplot vs Object-Oriented API (Summary Table)

| Feature          | Pyplot API     | Object-Oriented API      |
| ---------------- | -------------- | ------------------------ |
| Usage            | Simple & quick | Structured & powerful    |
| Control          | Limited        | Full control             |
| Best for         | Single plot    | Multiple / complex plots |
| Dataset size     | Small          | Large                    |
| Professional use | Less           | Recommended              |
